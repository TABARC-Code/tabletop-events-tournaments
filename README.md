# Tabletop Events Calendar — Tournaments

Swiss pairings and standings for competitive [Tabletop Events Calendar](https://github.com/TABARC-Code/tabletop-gaming-events-calendar) events.

**Not built yet.** This repo is reserved ahead of time, same as the rest of this family of plugins — its own repo from day one rather than a folder bolted onto the core plugin later.

The idea: an event flagged as a tournament gets round-by-round Swiss pairings, live standings, and tie-break handling, tied to the core plugin's existing ranking-circuit tags (ITC, UKTC, etc.) rather than inventing a second competitive-events system alongside it.

Requires [Tabletop Events Calendar](https://github.com/TABARC-Code/tabletop-gaming-events-calendar) once it exists — same dependency relationship as every other companion plugin in this family.
